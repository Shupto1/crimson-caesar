A control system is a device or set of device to manage, command, direct or regulate the behaviour of other device or system.

Describe the types of the system (?)
Reference: Saeed 1.3 - 1.6 Nise 1.3 - 1.5 Video: System Classification

The system are classified as

  1. Linear and Nonlinear system
  2. Time invariant and time varying system
  3. Continuous time and discrete time system
  4. Dynamic and static system
  5. Deterministic and stochastic system
  6. Single input and single output system

(i) Linear system:

A system is known as linear if and only if it posses both homogeneity and superposition properties.

Nonlinear system:

A system is said to be non-linear if it does not satisfy the superposition and homogeneity properties.

(ii) Time invariant system:

The system in which the parameters are independent of time and not varying with the time is called time invariant system.

Time varying system:

The system in which parameters (one or more) are varying with time is called time varying system.

(iii) Continuous time system:

The system in which the variables are the function of continuous time variable (t) is called continuous time system.

Discrete time system:

The system in which the variables are defined at only specified instants of time is called discrete time system.

(iv) Dynamic system (System with Memory):

A system is called dynamic if its output at any present instant depends not only on the input at that instant, but also on past inputs and the system's stored energy / previous state. Dynamic systems contain energy storage elements (inductors, capacitors, masses, springs) and are mathematically modeled by differential or difference equations.

Static system (Memoryless System):

A system is called static (or memoryless) if its output at any present instant depends strictly on the input at that exact same instant, independent of past or future values. Static systems contain no energy storage elements and are mathematically modeled by purely algebraic equations (e.g., a pure resistive network or an ideal proportional amplifier).

(v) Stochastic system:

In stochastic systems for a given input, the output is uncertain, only probability can be predicted.

Deterministic system:

In deterministic systems its output could be exactly determined for a given input.

(vi) Input-Output Dimension Classifications:

  • SISO (Single-Input Single-Output): System with exactly one control input and one controlled output.
  • SIMO (Single-Input Multiple-Output): System with one input driving multiple observed outputs.
  • MISO (Multiple-Input Single-Output): System having multiple inputs that produce a single combined output.
  • MIMO (Multiple-Input Multiple-Output): Multivariable system with multiple control inputs and multiple controlled outputs, typically analyzed using matrix-based state-space techniques.

Components of closed loop systems:

Command Input → [Reference Input Element] → (± Error Detector) → [Control Element] → [Controlled System] → Controlled Output
↑ feedback from output through [Feedback Element] back to error detector

  1. Command: The command is the externally produced input and independent of the feedback control system.
  2. Reference input element: This produce the standard signals proportional to the command.
  3. Error detector: The error detector receives the measured signal and compares it with reference input.
  4. Control element: This regulates the output according to the signal obtained from error detector.
  5. Controlled system: This element feed back — this represent what we are controlling by the feedback loop.
  6. Feedback element: This element feed back the output to the error detector for comparison with the reference input.

Define the term sensitivity? What is the effect of feedback on it?
Reference: Nise 7.5 - 7.7 Video: Feedback & Sensitivity

Ans: The sensitivity of the overall gain of a system $M$ to the variation in forward path gain $G$ is defined as the ratio of percentage change in $M$ to the percentage change in $G$:

$$S^M_G = \frac{\partial M / M}{\partial G / G} = \frac{\partial M}{\partial G} \cdot \frac{G}{M}$$

Consider the canonical closed-loop feedback system:

$V_i(s) \longrightarrow \boxed{\Sigma} \longrightarrow \boxed{G} \longrightarrow V_o(s)$, with feedback block $\boxed{H}$

The closed-loop transfer function (overall gain) is:

$$M = \frac{G}{1 + GH} \implies \frac{G}{M} = 1 + GH$$

Differentiating $M$ with respect to $G$ using the quotient rule:

$$\frac{\partial M}{\partial G} = \frac{(1 + GH)\cdot 1 - G \cdot H}{(1 + GH)^2} = \frac{1}{(1 + GH)^2}$$

Substituting $\frac{\partial M}{\partial G}$ and $\frac{G}{M}$ into the sensitivity definition:

$$S^M_G = \frac{1}{(1 + GH)^2} \cdot (1 + GH) = \frac{1}{1 + GH}$$

So the feedback can increase or decrease the sensitivity of a system.

Reference: Saeed 1.3 - 1.6 Nise 1.3 - 1.5 Video: System Type & Order

R(s)→(±)→[s(s+1)/s²(s+2)]→c(s), unity feedback

Soln: The characteristic eqn.

Step 1: Simplify $G(s)H(s)$ by canceling common pole-zero:

$$G(s)H(s) = \frac{s(s+1)}{s^2(s+2)} = \frac{s+1}{s(s+2)}$$

Note on pole-zero cancellation: The factor $s$ in the numerator cancels one pole at $s = 0$ in the denominator, yielding the minimal transfer function.

Step 2: Determine System Type:

The simplified open-loop transfer function has denominator $s(s+2)$. The power of $s$ at origin is 1 ($s = 0$).

∴ The number of net open-loop poles at the origin is 1, so Type = 1.

Step 3: Determine System Order:

The closed-loop characteristic equation is:

$$1 + G(s)H(s) = 0 \implies 1 + \frac{s+1}{s(s+2)} = 0$$

$$\implies s(s+2) + (s+1) = s^2 + 3s + 1 = 0$$

The highest power of $s$ in the characteristic equation is 2, so Order = 2.

(Exam Tip: If evaluated without pole-zero cancellation, uncancelled order is 3 and uncancelled type is 2; however, standard control engineering requires canceling common factors to determine true dynamic order and net type).

[2023-1-a] [3 Marks] What is feedback? What type of feedback is employed in control systems?
Reference: Saeed 1.3 - 1.6 Nise 1.3 - 1.5 Video: Feedback Types [2023-1-a]

1. Definition of Feedback:

Feedback is the property of a system by which the output (or a portion of it) is measured and fed back to the input, where it is compared with the reference input signal to generate an error signal that controls the system output.

2. Types of Feedback Employed in Control Systems:

  1. Negative Feedback (Degenerative Feedback):
    • The feedback signal is subtracted from the reference input signal: $E(s) = R(s) - H(s)C(s)$.
    • Application & Utility: Most widely employed in closed-loop control systems because it improves system stability, reduces sensitivity to parameter variations, widens bandwidth, and minimizes non-linear distortions.
  2. Positive Feedback (Regenerative Feedback):
    • The feedback signal is added to the reference input signal: $E(s) = R(s) + H(s)C(s)$.
    • Application & Utility: Used in electronic oscillators, Schmitt triggers, and regenerative amplifiers. It increases gain but generally degrades system stability if unmonitored.
[2023-1-b] [3 Marks] What is block diagram? What are the basic components of block diagram?
Reference: Saeed 1.3 - 1.6 Nise 1.3 - 1.5 Video: Block Diagram Components [2023-1-b]

1. Definition of Block Diagram:

A block diagram is a pictorial representation of the cause-and-effect relationships and signal flow between functional components in a control system, where each component is represented by a block containing its transfer function.

2. Basic Components of a Block Diagram:

  • Blocks: Represent functional elements or transfer functions $G(s)$ relating input to output ($C(s) = G(s) R(s)$).
  • Summing Junctions ($\Sigma$): Symbolized by circles with $+$ and $-$ signs, used to algebraically sum or subtract two or more signals ($E(s) = R(s) \pm B(s)$).
  • Take-off Points (Pick-off Points): Points where a signal is branched to feed multiple parallel paths without changing the signal magnitude or properties.
  • Arrows / Directed Lines: Indicate the direction of signal transmission throughout the control network.
[2023-5-a] [3 Marks] Explain the functions of Adaptive control system.
Reference: Saeed 11.1 - 11.10 Video: Adaptive Control [2023-5-a]

An Adaptive Control System is a sophisticated control system that can adjust its parameters automatically to adapt to real-time changes in plant dynamics and environmental disturbances. It consists of three primary functions:

  1. 1. Identification Function:
    • The system continuously measures and estimates the dynamic characteristics of the plant (such as parameters, states, or transfer functions) by observing input and output signals in real-time.
  2. 2. Decision Function:
    • The system compares the identified parameters with a desired set of performance indices or reference models to decide how to adjust controller parameters (like gains) to optimize performance.
  3. 3. Modification Function:
    • The system implements the decision by tuning the controller coefficients or modifying the control law parameters in real-time to drive the plant to the desired state.

Force-Voltage (F-V) Analogy (Loop / Mesh Analysis)

In Force-Voltage analogy, the mechanical force equation is compared with the electrical mesh/loop equation governed by Kirchhoff's Voltage Law (KVL: $\sum v = 0$):

  • Force $f(t)$ $\longleftrightarrow$ Voltage $v(t)$
  • Velocity $u(t) = \dot{x}$ $\longleftrightarrow$ Current $i(t) = \dot{q}$
  • Displacement $x(t)$ $\longleftrightarrow$ Electric charge $q(t)$
  • Mass $m$ $\longleftrightarrow$ Inductance $L$ ($m\ddot{x} \leftrightarrow L\frac{di}{dt}$)
  • Damping coefficient $D$ $\longleftrightarrow$ Resistance $R$ ($D\dot{x} \leftrightarrow Ri$)
  • Spring stiffness $K$ $\longleftrightarrow$ Reciprocal Capacitance (Elastance) $1/C$ ($Kx \leftrightarrow \frac{1}{C}\int i\,dt$)

Force-Current (F-I) Analogy (Nodal Analysis)

In Force-Current analogy, the mechanical force equation is compared with the electrical nodal equation governed by Kirchhoff's Current Law (KCL: $\sum i = 0$):

  • Force $f(t)$ $\longleftrightarrow$ Current $i(t)$
  • Velocity $u(t) = \dot{x}$ $\longleftrightarrow$ Voltage $v(t)$
  • Displacement $x(t)$ $\longleftrightarrow$ Magnetic flux linkage $\phi(t)$
  • Mass $m$ $\longleftrightarrow$ Capacitance $C$ ($m\ddot{x} \leftrightarrow C\frac{dv}{dt}$)
  • Damping coefficient $D$ $\longleftrightarrow$ Conductance $G = 1/R$ ($D\dot{x} \leftrightarrow Gv$)
  • Spring stiffness $K$ $\longleftrightarrow$ Reciprocal Inductance $1/L$ ($Kx \leftrightarrow \frac{1}{L}\int v\,dt$)

Describe the rules of the block diagram reduction method with example (4).
Reference: Saeed 1.23, 1.24.1, 1.24.2 Video: Block Diagram Reduction Rules

Rule-1: Blocks in cascade

R(s) →[G1(s)]→ C1(s) →[G2(s)]→ C(s)  ≡  R(s) →[G1(s)G2(s)]→ C(s)

Rule-2: Blocks in parallel

R(s) splits into [G11(s)], [G12(s)], [G13(s)] summed → C(s)  ≡  R(s) →[G11(s)+G12(s)+G13(s)]→ C(s)

Rule-3: Moving a take off point ahead of a block

R(s) →[G1(s)]→ C(s), tapped after block  ≡  R(s) →[G1(s)]→ C(s), with tap-off passed through [G1(s)] to match

Rule-4: Moving a take off point after the block

R(s) tapped before [G1(s)] → C(s)  ≡  R(s) →[G1(s)]→ C(s), with tap-off after block passed through [1/G1(s)]

Rule-5: Moving a summing point beyond a block

x,y →(±)→ [G1(s)] → C(s), where C(s)=G1(s)(x−y)  ≡  x→[G1(s)]→(±)← y→[G1(s)], → C(s), where C(s)=G1(s)(x−y)

Rule-6: Moving a summing point ahead of a block

R(s) →[G1(s)]→(± with x(s))→ C(s), where C(s)=R(s)G1(s)±x(s)  ≡  R(s)→(±)→[G1(s)]→C(s), with x(s) passed through [1/G1(s)] before the junction

Rule-7: Interchanging two summing points

x→(±y)→(±z)→ x−y+z  ≡  x→(±z)→(±y)→ x+z−y

Rule-8: Moving a take off point beyond a summing point

x→(±z)→ x−z, tapped after  ≡  x→(±z)→x−z, with an extra summing junction combining x and −z tap paths

Rule-9: Moving a take off point ahead of a summing point

x→(±y)→ x+y, tapped after (giving x+y)  ≡  x tapped before junction, y separately combined, both producing x+y outputs at two points

Rule-10: Eliminating a feedback loop (Canonical Closed-Loop Reduction)

$$R(s) \longrightarrow \boxed{\Sigma} \longrightarrow \boxed{G(s)} \longrightarrow C(s) \quad \text{with feedback } \boxed{H(s)} \quad \equiv \quad R(s) \longrightarrow \boxed{\frac{G(s)}{1 \pm G(s)H(s)}} \longrightarrow C(s)$$

(Use $+$ for negative feedback, and $-$ for positive feedback. Parallel forward paths combine additively as $G_1 \pm G_2$ as per Rule 2).

1. Statement of Mason's Gain Formula:

The overall gain (transfer function) of a system represented by a signal flow graph is given by:

$$T = \frac{C(s)}{R(s)} = \frac{\sum_{k} P_k \Delta_k}{\Delta}$$ where:
  • $P_k$: Gain of the $k$-th forward path.
  • $\Delta$: System determinant $= 1 - \sum L_i + \sum L_i L_j - \sum L_i L_j L_m + \dots$
  • $L_i$: Loop gains of individual closed loops.
  • $L_i L_j$: Product of gains of two non-touching loops.
  • $\Delta_k$: Path determinant for path $k$ (obtained by removing loops touching path $k$).

2. Calculations:

  1. Forward Paths: $P_1 = G_1 G_2 G_3 G_4$, $P_2 = G_1 G_5$.
  2. Loops: $L_1 = -G_2 H_1$ (nodes $X_1, X_2$), $L_2 = -G_3 H_2$ (nodes $X_2, X_3$). No non-touching loops.
  3. Determinant: $\Delta = 1 + G_2 H_1 + G_3 H_2$.
  4. Path Determinants: $\Delta_1 = 1$; for $P_2 = G_1 G_5$ (visiting nodes $R \to X_1 \to C$), it does not touch loop $L_2$ (visiting nodes $X_2 \to X_3 \to X_2$), so $\Delta_2 = 1 - L_2 = 1 + G_3 H_2$.
  5. Transfer Function: $$\frac{C(s)}{R(s)} = \frac{G_1 G_2 G_3 G_4 + G_1 G_5(1 + G_3 H_2)}{1 + G_2 H_1 + G_3 H_2} \quad \text{(Ans.)}$$
[2024-2-c] [4 Marks] What are the limitations of Mason's Gain Formula? How are the limitations overcome in SFG?
Reference: Saeed 1.25 - 1.32 Nise 5.4 - 5.5 Xavier 3.13 - 3.14 Video: Limitations of Mason's Gain [2024-2-c]

1. Limitations of Mason's Gain Formula:

  • It requires the system to be linear and time-invariant (LTI). It cannot be applied to non-linear or time-varying systems.
  • Finding all loops, particularly pairs and triplets of non-touching loops, becomes highly complex and prone to human error for large, heavily coupled networks.
  • The formula cannot be applied to physical layouts directly; the block diagram must first be converted into a signal flow graph.

2. How limitations are overcome in SFG:

  • Overcome by using computer-aided algorithms (like cycle-finding and DFS tree traversal) to systematically extract paths and loop structures without human error.
  • System reduction rules (such as node elimination or parallel/series branch simplification) can be used to shrink the SFG graph size before applying the formula.

Transient Response Design via Gain Adjustment

Reference: Nise 8.7

Once the root locus is sketched, a designer can select a desired closed-loop pole location on the locus that meets transient response specifications (such as peak time, settling time, and percent overshoot). The corresponding gain K is then calculated using the magnitude condition.

Design Procedure:

  1. Determine the desired closed-loop pole position from the transient response specifications. For a second-order underdamped system:
    ζ (damping ratio) is found from the desired percent overshoot: %OS = e−πζ/√(1−ζ²) × 100.
    ωn (natural frequency) is found from the desired peak time or settling time.
  2. The desired pole is at s = −ζωn ± jωn√(1−ζ²).
  3. Verify that this point lies on the root locus using the angle condition: ∠G(s)H(s) = ±180°(2K+1).
  4. Calculate the gain K using the magnitude condition: K = 1 / |G(s)H(s)| evaluated at the desired pole location.

Example: For G(s) = K/[s(s+4)], if we want 20% overshoot and Tp = 2 sec:

  • ζ = 0.456 (from %OS formula)
  • ωn = π / (Tp √(1−ζ²)) = 1.765 rad/s
  • Desired pole: s = −0.805 ± j1.571
  • Verify angle condition and compute K from magnitude condition.

This is the simplest form of control design using root locus — only the gain K is adjusted without adding any compensator.

Definitions of Transient Response Specifications:

  • i) Peak Time ($t_p$): The time required for the response to reach the first peak of the overshoot. Formula: $t_p = \frac{\pi}{\omega_d}$ where $\omega_d = \omega_n\sqrt{1-\zeta^2}$.
  • ii) Rise Time ($t_r$): The time required for the response to rise from $0\%$ to $100\%$ of its final value (for underdamped systems). Formula: $t_r = \frac{\pi - \beta}{\omega_d}$ where $\beta = \tan^{-1}\left(\frac{\sqrt{1-\zeta^2}}{\zeta}\right)$.
  • iii) Delay Time ($t_d$): The time required for the response to reach $50\%$ of its final value for the first time. Formula: $t_d \approx \frac{1 + 0.7\zeta}{\omega_n}$.
  • iv) Maximum Overshoot ($M_p$): The maximum peak value of the response curve measured from unity. Formula: $M_p = e^{-\left(\frac{\zeta\pi}{\sqrt{1-\zeta^2}}\right)} \times 100\%$.
[2023-4-b] [3 Marks] Define transient response and steady-state response of a control system. What is the fundamental difference between them?
Reference: Saeed 2.5 Video: Transient vs Steady State [2023-4-b]

1. Transient Response:

The part of the system response that goes from the initial state to the final state. It represents the temporary behavior of the system output immediately after a change in input, which decays to zero as $t \to \infty$.

2. Steady-State Response:

The behavior of the system output as time approaches infinity ($t \to \infty$) after the transient response has completely died out.

3. Fundamental Difference:

The transient response is a temporary dynamic phase representing speed, stability, and overshoot, whereas the steady-state response is a permanent phase representing final accuracy and steady-state alignment with the reference input.

Derivation of Rise Time ($t_r$):

Underdamped second-order step response: $$c(t) = 1 - \frac{e^{-\zeta \omega_n t}}{\sqrt{1-\zeta^2}} \sin(\omega_d t + \theta)$$ where $\theta = \cos^{-1}(\zeta)$.

  1. By definition, at $t = t_r$, the response reaches $100\%$ of its final value ($c(t_r) = 1$): $$1 - \frac{e^{-\zeta \omega_n t_r}}{\sqrt{1-\zeta^2}} \sin(\omega_d t_r + \theta) = 1$$
  2. This requires the sine term to vanish: $$\sin(\omega_d t_r + \theta) = 0 \implies \omega_d t_r + \theta = \pi$$
  3. Solving for $t_r$: $$t_r = \frac{\pi - \theta}{\omega_d} \quad \text{where } \theta = \cos^{-1}(\zeta) = \tan^{-1}\left(\frac{\sqrt{1-\zeta^2}}{\zeta}\right) \quad \text{(Ans.)}$$

Steady-State Error ($e_{ss}$):

Steady-state error is the difference between the desired reference input and the actual system output response in the limit as time approaches infinity ($t \to \infty$):

$$e_{ss} = \lim_{t \to \infty} e(t) = \lim_{s \to 0} s E(s) = \lim_{s \to 0} \frac{s R(s)}{1 + G(s)H(s)}$$ where $E(s)$ is the Laplace transform of the error signal.

Bode plot

Reference: Saeed 4.10 - 4.13
Topic Video: Control System Lectures - Bode Plots, Introduction & Stability • Brian Douglas

Bode plot is a graphical representation of the transfer function for determining the stability of the control system.

Define phase margin, gain margin, phase cross over frequency and gain cross over frequency.

Reference: Saeed 4.4 - 4.9

Phase Margin: The phase margin is that amount of additional phase lag at the gain crossover frequency required to bring the system to the verge of instability.

Gain margin: The gain margin is the reciprocal of the magnitude |G(jω)| at the frequency at which the phase angle is −180°.

∴ Gain margin (GM) Kg = 1/|G(jω)|

Gain Margin: Gain margin is defined as the margin in gain allowable by which gain can be increased till system reaches on the verge of instability.

Phase Margin: For gain the additional phase lag can be introduced without affecting the magnitude plot.

Gain Crossover Frequency: The gain crossover frequency is the frequency at which the magnitude of the open-loop transfer function is

equal to 1 (or 0 dB in logarithmic scale).

Phase crossover frequency: The phase crossover frequency at which the phase angle of the open-loop transfer function is −180° (or equivalently, −π radians).

Routh-Hurwitz criterion is the algebraic method of determining the location of poles of a characteristic equation with respect to the left and right half of the s-plane without actually solving the equation.

State and expression Routh's stability criterion?
Reference: Saeed 5.6 - 5.8 Nise 6.1 - 6.4 Xavier 7.2 - 7.5 Video: Routh's Stability Criterion

Soln:

Routh-Hurwitz criterion states that the system is stable if and only if all the elements in the first column have the same algebraic sign. If all element are not of the same sign the the number of sign changes of the elements in first column equal the number of roots of the characteristic equation in the right half of the s-plane.

Consider the following characteristic polynomial

a0sn + a1sn-1 + ... + an = 0  —(1)

Where the coefficients a0,a1,...an are all of the same sign and none is zero.

Step 1: Arrange all the coefficients of equation(1) in two rows

Row 1a0a2a4 ...
Row 2a1a3a5 ...

Step 2: From these two rows form a third row

Row 1a0a2a4 ...
Row 2a1a3a5 ...
Row 3b1b3b5 ...

Where, b1 = −(1/a1) · det[a0 a2; a1 a3]

b3 = −(1/a1) · det[a0 a4; a1 a5]

Step 3: From second and third row, form a fourth row

Row 1a0a2a4 ...
Row 2a1a3a5 ...
Row 3b1b3b5 ...
Row 4c1c3c5 ...

Where, c1 = −(1/b1) · det[a1 a3; b1 b3]

c3 = −(1/b1) · det[a1 a5; b1 b5]

Step 4: Continue this procedure of forming a new rows.

Special Case 1: First Element of Any Row is Zero (ε Method)
Reference: Saeed 5.7 Nise 6.3 Xavier 7.3 Video: Special Case 1: First Element Zero

Condition: If the first element in any row of the Routh table becomes zero while other elements in that row are non-zero, division by zero occurs in subsequent rows.

  4. Alternatively, substitute $s = 1/z$ into the original characteristic equation and analyze the resulting polynomial in $z$.

Condition: If all the elements of a row become zero, this indicates the presence of roots symmetrically located about the origin in the $s$-plane (e.g. pairs of real roots of opposite sign $\pm \sigma$, purely imaginary pairs $\pm j\omega$, or complex quadruplets $\pm \sigma \pm j\omega$).

[2023-7-a] [4 Marks] What is characteristics equation of a closed loop control system? How is the necessary but not sufficient condition for stability of the system determined from characteristics equation?
Reference: Saeed 5.1 - 5.5 Video: Characteristic Equation Stability [2023-7-a]

1. Characteristic Equation:

The equation obtained by equating the denominator of the closed-loop transfer function to zero: $$1 + G(s)H(s) = 0$$

In polynomial form: $$a_n s^n + a_{n-1} s^{n-1} + \dots + a_1 s + a_0 = 0$$

2. Necessary but Not Sufficient Condition for Stability:

  • Condition: All coefficients of the characteristic equation polynomial ($a_n, a_{n-1}, \dots, a_0$) must be positive (or have the same sign) and none of the coefficients must be zero (no missing powers).
  • Why it is not sufficient: Even if all coefficients are positive and present, the system may still be unstable because some roots can lie in the Right-Half s-Plane. E.g., $s^3 + s^2 + 2s + 8 = 0$ has all positive and present coefficients, yet its roots are $s=-2$ and $s = 0.5 \pm j1.93$ (unstable).

[2024-4-c] [6 Marks] Use the Nyquist criterion to determine whether the closed-loop system having the following open-loop transfer function is stable or not. G(s) = (1+4s)/[s^2(1+s)(1+2s)]
Reference: Saeed 5.17 Video: Nyquist Stability Analysis [2024-4-c]

Nyquist Stability Assessment:

Open-Loop Transfer Function: $$G(s)H(s) = \frac{1+4s}{s^2(1+s)(1+2s)}$$

  1. Open-Loop Poles ($P$ in RHP):
    • Poles are at $s = 0, 0, -1, -0.5$. None lie in the open Right-Half Plane (RHP), so $P = 0$.
    • There is a double pole at the origin ($s^2$), requiring a small semicircular indentation around the origin in the Nyquist contour.
  2. Frequency Response & Phase Crossover Frequency ($\omega_{pc}$):

    Substitute $s = j\omega$ and rationalize the denominator:

    $$G(j\omega) = \frac{1 + j4\omega}{(j\omega)^2 (1 + j\omega)(1 + j2\omega)} = \frac{1 + j4\omega}{-\omega^2 (1 - 2\omega^2 + j3\omega)}$$

    Multiplying numerator and denominator by $(1 - 2\omega^2 - j3\omega)$ yields:

    $$G(j\omega) = \frac{-(1 + 10\omega^2) + j\omega(8\omega^2 - 1)}{\omega^2(1+\omega^2)(1+4\omega^2)}$$

    At the phase crossover frequency $\omega_{pc}$, the imaginary part equals zero:

    $$\text{Im}[G(j\omega)] = 0 \implies 8\omega^2 - 1 = 0 \implies \omega_{pc} = \frac{1}{2\sqrt{2}} \approx 0.354\text{ rad/s}$$
  3. Magnitude at Phase Crossover:

    Substitute $\omega_{pc}^2 = \frac{1}{8} = 0.125$ into the real part:

    $$G(j\omega_{pc}) = \frac{-(1 + 10 \times 0.125)}{0.125(1 + 0.125)(1 + 4 \times 0.125)} = \frac{-2.25}{0.125 \times 1.125 \times 1.5} = -\frac{32}{3} \approx -10.67$$

    Since $G(j\omega_{pc}) = -10.67 < -1$, the negative real-axis intercept lies to the left of the critical point $(-1, j0)$.

  4. Nyquist Plot Encirclements ($N$):

    Because the real-axis intercept at $-10.67$ lies beyond $-1$, and taking into account the $2 \times 180^\circ = 360^\circ$ clockwise detour at infinity corresponding to the double pole at the origin, the complete Nyquist plot encircles the critical point $(-1, j0)$ exactly two times in the clockwise direction ($N = -2$).

  5. Apply Nyquist Stability Criterion: $$N = P - Z \implies -2 = 0 - Z \implies Z = 2$$

    where $Z$ is the number of closed-loop poles in the Right-Half $s$-Plane.

  6. Conclusion: Since $Z = 2 > 0$, the closed-loop system has two poles in the RHP and is strictly UNSTABLE.

State Transition Matrix (STM):

The state transition matrix $\Phi(t)$ characterizes the free response of a state model. It is computed as:

$$\Phi(t) = e^{At} = \mathcal{L}^{-1}\{(sI - A)^{-1}\}$$

Calculation Steps:

  1. Calculate the characteristic matrix: $sI - A$.
  2. Compute the matrix inverse: $(sI - A)^{-1} = \frac{\text{adj}(sI - A)}{\det(sI - A)}$.
  3. Apply the Inverse Laplace Transform element-wise: $\Phi(t) = \mathcal{L}^{-1}\{(sI - A)^{-1}\} \quad \text{(Ans.)}$.

1. Two-Position Control (ON-OFF Control):

A control action in which the controller output has only two discrete states (fully ON or fully OFF) depending on whether the error signal $e(t)$ is positive or negative. The control law is:

$$u(t) = \begin{cases} U_{\text{max}} & \text{for } e(t) > 0 \\ U_{\text{min}} & \text{for } e(t) < 0 \end{cases}$$

2. Dead Zone (Differential Gap):

The dead zone is a small range of error signal through which the controller output remains unchanged. It is intentionally introduced to prevent rapid switching (chattering), which causes excessive wear on switching elements (like relays or contactors).

Proportional-Integral (PI) Control Action:

PI control combines proportional control action (which is proportional to error) with integral control action (which is proportional to the integral of the error over time). The control law is:

$$m(t) = K_p e(t) + \frac{K_p}{T_i} \int_0^t e(t) dt$$ where $K_p$ is proportional gain and $T_i$ is integral time constant.

Transfer Function: $$G_c(s) = K_p \left(1 + \frac{1}{T_i s}\right)$$.

Key Effects:

  • Eliminates steady-state error completely by increasing the system type by 1.
  • Adds a pole at the origin ($s=0$), which tends to decrease system stability and increase peak overshoot.

# এখন আমরা একটা derivation শিখব / proof যাই বল না কেন:
# একটা closed loop system দেখঃ 
# Input R(s) -> Comparator (+) -> Error E(s) -> Forward Plant G(s) -> Output C(s)
# Output C(s) feedbacks into H(s) -> Feedback signal B(s) -> feeds into Comparator (-)
# ==============================================================================

Rs_sym, Es_sym, Gs_sym, Cs_sym, Hs_sym, Bs_sym = sp.symbols('R(s) E(s) G(s) C(s) H(s) B(s)')

# এখানে দেখ কি বলছে কোনটা;
# R(s) = Reference input
# E(s) = Actuating signal or error signal
# G(s) = Forward path transfer function
# C(s) = Output signal
# H(s) = Feedback transfer function
# B(s) = Feedback signal

# এখন দেখ, from figure;
# C(s) = G(s) * E(s)  ......(1)  [কারণ দেখ E(s) G(s) এর সাথে মিলিত হচ্ছে, then output C(s) হচ্ছে]
# B(s) = H(s) * C(s)  ......(2)
# E(s) = R(s) - B(s)  ......(3)  [comparator এর output]

# Now, putting the value of C(s) from eqn (1) in eqn (2):
# B(s) = H(s) * G(s) * E(s)  ......(4)
# B(s) / E(s) = G(s) * H(s) -> এই B(s)/E(s) কেই বলা হয় open loop transfer function.
open_loop_TF = Gs_sym * Hs_sym

# Now putting the value of E(s) from eqn (3) in eqn (1);
# C(s) = G(s) * [R(s) - B(s)]
# C(s) = G(s)*R(s) - G(s)*B(s)  ......(5)

# Now putting the value of B(s) from eqn (2) in eqn (5):
# C(s) = G(s)*R(s) - G(s)*H(s)*C(s)
# C(s) + G(s)*H(s)*C(s) = G(s)*R(s)
# C(s) * [1 + G(s)*H(s)] = G(s)*R(s)
# C(s) / R(s) = G(s) / (1 + G(s)*H(s))
closed_loop_TF = Gs_sym / (1 + Gs_sym * Hs_sym) # closed loop transfer function

# 2) closed loop control system এ থাকে -> i) open loop transfer function, ii) Closed loop transfer function

# Mathematical Modeling of Mechanical System
# প্রথমেই আমরা জানব mechanical system কি?
# motion type এর উপর ভিত্তি করে mechanical system দুই ধরনের:
# i) Translational mechanical system [এই system এ কোনো object এর motion হয় straight line বরাবর]
# ii) Rotational mechanical system [এই system এ কোনো object এর motion হয় circle এ]
# ==============================================================================

# এখন দেখব translational mechanical system এর parameter:
# Parameter | symbol | একক
# i) Displacement | x | meter
# ii) Velocity | v = dx/dt | m/sec
# iii) Acceleration | a = dv/dt = d^2x/dt^2 | m/sec^2
# iv) Force | F | N

# কিছু basic নিয়ম: আমরা যখন modeling করতে যাব তখন অনেক ধরনের object পাবা 
# তো ধর mass জানি আমরা। তখন আমরা Force calculation করব F = m*a দ্বারা।
# যদি থাকে damper (damping constant B), তখন: F = B * v = B * dx/dt
# যদি spring থাকে (spring constant K), তখন: F = K * x

# Rotational mechanical system এরও কিছু parameter আছে:
# i) Rotational angle [Angular displacement] | theta | rad
# ii) Angular velocity | omega = d(theta)/dt | rad/sec
# iii) Angular acceleration | alpha = d(omega)/dt = d^2(theta)/dt^2 | rad/sec^2
# iv) Torque | T | N-m
# v) Moment of inertia | I or J | kg-m^2

# translational mechanical system এর parameter এর সাথে rotational mechanical system এর parameter correlate করা যায়।
# translational velocity v -> rotational angular velocity omega
# translational displacement x -> rotational angular displacement theta
# translational acceleration a -> rotational angular acceleration alpha
# translational Force F -> rotational Torque T
# translational mass m -> rotational moment of inertia I or J

# * যদি আমাদের জানা থাকে mass ও moment of inertia; then torque, T = I * alpha
# * যদি জানা থাকে damper তখন, T = B * omega
# * যদি জানা থাকে spring constant তখন, T = K * theta

# এখন একটু Details এ দেখি বিষয়গুলো:
# Translational Mechanical system এর basic elements হলঃ 1) Mass (m), 2) Damper (B), 3) spring (K)
# Mass: মনে কর একটা surface এর উপর mass m রাখা এবং তাকে force F apply করা হল। 
# তাহলে এর displacement হবে x ও acceleration a. force এর equation হবে F = m*a = m * d^2x/dt^2
# Damper: এখানে একটা fixed object এর সাথে damper connected. একে F force apply করা হলে 
# displacement x ও velocity v হবে। equation: F = B * v = B * dx/dt
# Spring: একটা fixed support এর সাথে spring connected. force F apply করলে displacement x হবে direction এ। 
# Restoring force F displacement এর proportional: F = K * x

# তাহলে equation গুলোর Laplace ও করে ফেলি (assuming zero initial conditions):
# F = m * d^2x/dt^2  => F(s) = m * s^2 * X(s)
# F = B * dx/dt      => F(s) = B * s * X(s)

# একইভাবে এখন Rotational Mechanical system এর elements গুলো দেখি:

# এবার electrical system দেখি একটা (Series R-L-C circuit with voltage source V):
# Voltage across resistance: V_R = I * R
# Voltage across inductor: V_L = L * dI/dt
# Voltage across capacitor: V_C = (1 / C) * Integral(I dt)
# Total voltage: V = V_L + V_R + V_C = L * dI/dt + I * R + (1 / C) * Integral(I dt)
# আমরা জানি, current I = dq/dt (where q is charge), so Integral(I dt) = q and dI/dt = d^2q/dt^2

# Question 1: Define stability and classify it.
# Answer: A system is said to be stable if its response cannot be made to increase indefinitely 
# by the application of a bounded input excitation.
# [যদি তুমি কোনো system এ excitation input দাও, দিয়ে দেখ system টার output indefinite, 
# মানে infinity এর দিকে যাচ্ছে তাহলে system টি un-stable]
# If the output approaches towards infinite value for sufficiently large time, the system is said to be unstable.
# Stability can be classified into two types: i) Absolute stability, ii) Relative stability.
# i) Absolute stability: Absolute stability refers to the condition of whether the system is stable or unstable.
# ii) Relative stability: Relative stability refers to the condition/degrees of stability which determines how stable or unstable the system is.

# Answer: Root locus is a graphical representation of the closed-loop poles as a system
# parameter (usually gain K) is varied from 0 to infinity in the complex s-plane.
# The general construction rules include:
# 1. Symmetry: The root locus is symmetrical about the real axis.
# 2. Number of branches: N = max(P, Z).
# 3. Starting/Ending points: Branches start at open-loop poles (K = 0) and end at zeros or infinity (K = inf).
# 4. Real axis segments: A point on the real axis belongs to the root locus if the total number
#    of open-loop poles and zeros to its right is odd.
# 5. Asymptotes: Branches tending to infinity follow asymptotes at angle phi = (2k+1)*180 / (P - Z)
#    intersecting the real axis at centroid sigma_A = (sum(poles) - sum(zeros)) / (P - Z).
# 6. Breakaway/Break-in points: Derived from dK/ds = 0.
# 7. Angle of departure/arrival: phi_d = 180 - (sum(theta_p) - sum(theta_z)).
# 8. Imaginary axis crossing: Determined using the Routh-Hurwitz array or setting s = j*omega.
